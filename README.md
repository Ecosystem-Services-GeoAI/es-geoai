# 2026 IALE Workshop: Ecosystem Services Mapping

This repository contains the materials, resources, and supporting information for the **2026 IALE Workshop on Ecosystem Services Mapping**.

## Workshop Website

The workshop webpage is available at:

[2026 IALE Workshop: Ecosystem Services Mapping](https://ecosystem-services-geoai.github.io/es-geoai-programs/workshops/2026_IALE_Workshop_ES_Mapping)

## Overview

This workshop introduces approaches for **mapping and analyzing ecosystem services using geospatial data, GIS, remote sensing, and GeoAI methods**. The materials are designed to provide participants with both conceptual background and hands-on experience with spatial data and analytical workflows relevant to ecosystem services research.

## Workshop Materials

The workshop materials may include:

- Presentation slides
- Hands-on exercises
- Example datasets
- Python or GIS scripts
- Mapping and visualization examples
- Supporting documentation
- Additional learning resources
